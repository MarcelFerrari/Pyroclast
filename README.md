# Pyroclast

Pyroclast is a high‑performance, modular Python framework for geodynamic modeling.
It focuses on the **marker‑in‑cell** method to solve a coupled thermomechanical system of PDEs.

This project is currently **under active development**. APIs, structure, and functionality are subject to change.

A brief description of the mechanical solver can be found here https://arxiv.org/abs/2509.19061

Stay tuned for documentation, benchmarks, and examples as development progresses.
